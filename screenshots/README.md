## How to Take Screenshots

### Android (Expo Go)
1. Run `npx expo start`
2. Open app in Expo Go on Android device
3. Take screenshots using device screenshot function
4. Transfer to this folder

### iOS (Expo Go)
1. Run `npx expo start`
2. Open app in Expo Go on iOS device
3. Take screenshots using device screenshot function
4. Transfer to this folder

### Emulator/Simulator
- **Android Studio**: Use screenshot button in emulator toolbar
- **iOS Simulator**: Cmd+S to save screenshot

## Screenshot Guidelines

- Use high-quality images (PNG format)
- Show different features and states
- Include both light and dark mode
- Demonstrate responsive layouts
- Show error states and loading states
